# 架构设计文档

## 整体架构

```
┌─────────────────────────────────────────────────────┐
│                    用户浏览器                          │
└──────────────────────┬──────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────┐
│              Nginx 反向代理 (端口 80)                  │
└──────────┬───────────────────────────┬──────────────┘
           │                           │
┌──────────▼──────────┐   ┌───────────▼──────────────┐
│   Vue 3 前端          │   │   FastAPI 后端             │
│   (端口 5173)         │   │   (端口 8000)              │
│                      │   │                           │
│  - Vue Router        │   │  - JWT 认证               │
│  - Pinia Store       │   │  - RESTful API            │
│  - Element Plus      │   │  - SQLAlchemy ORM          │
│  - Axios             │   │  - Pydantic 验证           │
└──────────────────────┘   └───────────┬──────────────┘
                                       │
                          ┌────────────▼─────────────┐
                          │     数据库                 │
                          │  SQLite (开发)             │
                          │  PostgreSQL (生产)         │
                          └──────────────────────────┘
```

## 后端分层架构

```
app/
├── api/          # HTTP层：路由、请求/响应处理
├── services/     # 业务层：核心业务逻辑
├── models/       # 数据层：SQLAlchemy ORM模型
├── schemas/      # 验证层：Pydantic数据验证
├── utils/        # 工具层：通用工具函数
└── constants/    # 常量层：状态码、消息等
```

## 前端架构

```
src/
├── pages/        # 页面组件
├── components/   # 可复用组件
├── stores/       # Pinia状态管理
├── api/          # API调用封装
├── router/       # Vue Router路由
└── utils/        # 工具函数
```

## 数据库设计

8个核心表：
- users（用户）
- categories（分类）
- assets（资产）
- borrows（借用记录）
- maintenance_records（维护记录）
- asset_transfers（转移记录）
- operation_logs（操作日志）
- system_settings（系统设置）

## 安全设计

1. **JWT认证**：所有API需要Bearer Token
2. **RBAC权限**：管理员/主管/普通用户三级权限
3. **密码加密**：bcrypt哈希存储
4. **CORS配置**：限制允许的来源域名
